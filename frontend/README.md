# SMLE Frontend

This is the React-based frontend for the SMLE (Social Media Listening Engine) dashboard.

## Development

1.  **Install Dependencies**
    ```bash
    npm install
    ```

2.  **Start Dev Server**
    ```bash
    npm run dev
    ```
    Access the dashboard at `http://localhost:5173`

## Features
*   **React + Vite** for fast HMR.
*   **TailwindCSS** for styling.
*   **React Force Graph** for network visualization.
*   **Lucide React** for icons.
